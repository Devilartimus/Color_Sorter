## Описание задачи
Программа упорядочивает объекты трех цветов (красный, зеленый, синий) в соответствии с заданным отношением порядка. 

**Пример:**
```
Вход: С С З С К З З З К К С З С С К З
Правило: З < С < К
Выход: З З З З З З С С С С С С К К К К
```
## Требования к системе
- **Компилятор:** GCC 9.0+ / Clang 10.0+ / MSVC 2019+
- **CMake:** версия 3.15+
- **Стандарт C++:** 17
- **Библиотеки:** pthread (для Linux)

## Формат входных данных
### Файл с объектами (.txt)
Каждая строка представляет один объект:
```
Цвет;Данные
```
**Пример:**
```
З;Объект1
С;Данные2
К;Item3
З;12
G;1
Blue;28
```

### Поддерживаемые форматы цветов
| Русский | Английский | Полное название   |
|---------|------------|-------------------|
| К, к    | R, r       | Красный, Red      |
| З, з    | G, g       | Зеленый, Green    |
| С, с    | B, b       | Синий, Blue       |

## Использование программы
После запуска доступны следующие команды:

| Команда                  | Описание                                | Пример                    |
|--------------------------|-----------------------------------------|---------------------------|
| `set_rule <правило>`     | Установить правило сортировки           | `set_rule З < С < К`      |
| `load <файл>`            | Загрузить файл с объектами              | `load data.txt`           |
| `start`                  | Начать обработку                        | `start`                   |
| `stop`                   | Остановить обработку                    | `stop`                    |
| `results`                | Показать результаты сортировки          | `results`                 |
| `status`                 | Показать статус обработки               | `status`                  |
| `exit`                   | Выйти из программы                      | `exit`                    |

**Пример сессии:**
```
> set_rule G < B < R
Rule set: G < B < R
> load input.txt
File set: input.txt
> start
Processing started
> status
Processing: ACTIVE
Rule set: YES
> stop
Processing stopped
> results
G: Объект1
B: Данные2
R: Item3
> exit
```

## Особенности реализации

### Алгоритм сортировки
1. **Распределение по цветам:**
   - Объекты распределяются в 3 независимых контейнера
   ```cpp
   std::array<std::vector<ColoredObject>, 3> m_buckets;
   ```
2. **Формирование результата:**
   - Конкатенация контейнеров в порядке правила
   ```cpp
   for (Color c : m_rule) {
       m_result.insert(m_buckets[static_cast<int>(c)]);
   }
   ```

### Потоковая модель
| Поток          | Функционал                          | Механизмы синхронизации       |
|----------------|-------------------------------------|-------------------------------|
| **Producer** | Чтение файла и парсинг объектов    | `std::mutex` + `std::queue`   |
| **Consumer**  | Сортировка объектов по цветам      | `std::condition_variable`     |

### Обработка ошибок
- Некорректные строки пропускаются с предупреждением
- Проверка расширения файла (.txt)
- Валидация правил сортировки
- Защита от deadlock с таймаутами (100ms)

## Технические характеристики
1. **Производительность:**
   - Временная сложность: O(n)
   - Память: O(n)
   - Поддержка больших файлов (>1 млн объектов)

2. **Безопасность:**
   - Потокобезопасные контейнеры
   - RAII для управления ресурсами
   - Атомарные флаги для управления потоками

3. **Кроссплатформенность:**
   - Поддержка Windows/Linux
   - Независимость от графических библиотек
